# 🧀 Cheese

Welcome to **Cheese** – the cheesiest Python package this side of the dairy farm! 🐭🧀  

Spread some joy in your code with functions that are simple, delicious, and oh-so-creamy.

---

## 🌟 Features

- 🐭 **Simple & Small:** Bite-sized Python goodness.  
- 📦 **Packaged Perfectly:** Learn Python packaging while enjoying the cheese.  
- 🧀 **Lightweight:** No heavy dependencies, just pure cheddar fun.  

---

## 🚀 Installation

Enjoy your slice of Cheese by choosing one of the following methods:

1. **Install directly from PyPI**

   ```bash
   # Install the latest version
   pip install cheese

   # Or install a specific version
   pip install cheese==0.1.0

2. **Install directly from GitHub**

   pip install git+https://github.com/fela14/Cheese.git


3. **Installing Cheese locally** 

   # Build distribution
   python setup.py sdist bdist_wheel

   # Install locally
   pip install dist/cheese-0.1.0-py3-none-any.whl

Tip: Using a virtual environment is recommended to keep your dependencies isolated:

python3 -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

## 🧑‍💻 Usage

from cheese.cheddar import cake, master

print(cake())   # Output: This is my cake function
print(master()) # Output: This is my master function
